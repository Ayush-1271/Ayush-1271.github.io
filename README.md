# Ayush Ranjan — Portfolio

Personal portfolio for applied AI, NLP, retrieval systems, and cryptography research. The site is published at [ayush-1271.github.io](https://ayush-1271.github.io/).

## What you can explore

- **Home** — background, experience, selected work, research, and contact links.
- **Projects** — nine selected projects with descriptions and interactive walkthroughs where available.
- **Research** — context and links for the published ternary LFSR image-encryption paper.
- **Resume** — PDF versions linked from the site.

## Selected work

- [Novel Vault](https://github.com/Ayush-1271/Novel-Vault) — local FastAPI application for managing a personal library, download jobs, and PDF/EPUB/TXT exports.
- [RAG PDF Chat](https://github.com/Ayush-1271/rag-pdf-chat) — PDF question answering with streamed responses and page-level citations.
- [NoteMind](https://github.com/Ayush-1271/NoteMind) — persistent semantic memory for multi-agent workflows.
- [MangaLens](https://github.com/Ayush-1271/MangaLens) — Chrome extension for translating text in manga images.
- [MarketLens](https://github.com/Ayush-1271/MarketLens) — probabilistic forecasting project with uncertainty and reliability analysis.

The site describes these projects based on their repositories and published materials. Individual demos and external services can change independently of this static site.

## Run locally

This is a static site: HTML, CSS, JavaScript, and included assets. There is no package manifest or build step. Open `index.html` directly, or run any static file server from the repository root. The main pages are `index.html`, `projects.html`, and `research.html`.

## Publishing

The repository is configured as a GitHub Pages user site. Changes to the published branch are served at [https://ayush-1271.github.io/](https://ayush-1271.github.io/).

## Public files

The two resume PDFs in this repository are public because they are linked on the portfolio. Review their contact details and personal information before keeping them publicly accessible. Do not add credentials, private datasets, browser profiles, or downloaded third-party content.
