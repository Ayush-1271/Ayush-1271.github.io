# Ayush Ranjan — Portfolio Website

A static portfolio website built from HTML, CSS, and JavaScript. The pages present the portfolio, selected projects, and research.

## Pages and assets

- `index.html` — portfolio landing page
- `projects.html` — project descriptions
- `research.html` — research information
- `css/` and `js/` — site styles and browser-side behavior
- `Ayush_Ranjan.pdf` and `Ayush_Ranjan_ATS.pdf` — resume documents currently stored in the repository

## Preview locally

Open `index.html` in a browser, or serve the repository root with a local static web server. The repository has no package manifest or build command; the HTML, CSS, and JavaScript files are the site source.

## Publishing

This repository is named as a GitHub Pages user site. The published site URL depends on the repository's Pages settings and domain configuration.

## Privacy review

Both resume PDFs are included in this repository. Review them for personal details you do not want to make public.
